# Decisions

Dir holds decision records: hard-to-reverse, cross-cutting decisions with durable rationale.

## How to use

- Read relevant records before planning work that touches shared contracts, persistence, deployment, or module boundaries.
- Records shape planning, review, and vocabulary — not task tracking.
- Create or update only with explicit Lead agreement.
- Supersede stale records; don't silently rewrite history.

## Adding records

Use `_template.md`. Name with sortable date + slug:

```text
2026-05-01-use-tracker-artifacts-as-handoff-surface.md
```
